# Prohibition of Import and Export

**CUSTOMS (PROHIBITION OF IMPORT) ORDER 2023**

1.  Prior to any importation activity, individual needs to ensure that the goods to be imported are subjected to any prohibition or restriction under the Customs (Prohibition on Import) Order 2023.

2.   If the goods to be imported ​are subjected to this Order, the individual must fulfill all the requirements under this Order.

3.  ​Please refer to the following link for more information:​

[https://lom.agc.gov.my/act-view.php?type=pua&no=P.U.%20(A)%20117/2023](https://lom.agc.gov.my/act-view.php?type=pua&no=P.U.%20%28A%29%20117/2023&__ncforminfo=5pDn_wEX2kcDtulALgLJcXvA5FlqfS_1SkGiX1rb4wAXHtEj6wuyRgAcR1p--xOT5Jo4WXZNPauEzMP4Zbn2HBJSJIzRVnQhLZ7AoQ5yCQY=)

**CUSTOMS (PROHIBITION OF EXPORT) ORDER 2023**

1.  Prior to any exporting activity, individual needs to ensure that the goods to be exported are subjected to any prohibition or restriction under the Customs (Prohibition on Export) Order 2023.

2.  If the goods to be exported are subjected to this Order, the individual must fulfill all the requirements under this Order.

3.  Please refer to the following link for more information:
