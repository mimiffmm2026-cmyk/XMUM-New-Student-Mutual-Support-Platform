- 一份男女通用、54 项、只列**选项与边界**的规划表：不代填实测重量、机票票规、个人手续或采购结果。

### 01 称重预算

只填两个数：E7/E8（整包实称 kg）与 H7/H8（最近终称时间）；D 列分组合计、F 列距额度自动计算。

- 托运：本次额度 20kg，建议目标 18kg，分组预算合计 18kg。
- 手提：本次额度 7kg，建议目标 6kg，分组预算合计 6kg；全部手提合并（电脑包、小包都计入）。
- 自动状态文案：待整包称重 → 请填数字kg / 重量不能为负 / 0kg：确认未携带 → 超重，必须调整 → 未超额度；超预算目标 → 未超额度；另核件数/尺寸。

表内提示：

- 先减什么？未核清的食品 → 多余纸书/鞋子 → 大瓶洗护 → 多套床品/备用品；证件、必要药物、首晚所需不先删。
- 当地采购不等于已经落实：首晚物资须有供应方、时间地点、接收人和失败备选才算安排好。
- 预算只是分配工具：“26寸/20寸”不能代替含轮把尺寸，抽真空不能减少重量。
- 先称电脑＋所需充电器＋背包；不可把电脑包当成免费额外额度。
- 登机口临时改托运前：取出充电宝、备用锂电池、含电池设备；证件和必要药物仍随身，剩余物品请承运人确认。
- 实际称重才决定是否超额；未超 20/7kg 仍要核每段件数、尺寸、液体、电池与海关条件；允许携带与校内允许使用也不同。
- 称重不自动读取 02 表数量或重量组；新增物品先归入现有 T/S 组并重称。

#### 宿舍与首晚提示

- 学校提供床垫（中等偏硬，想睡软一点自购床褥）；枕头、被子、床单需自行准备，被子空调被即可。
- 自带床品更舒服：可真空压缩后托运（不减重量）或国内购买后海运；海运/本地购买要做好第一晚可能无床品可用的准备（呼应 R09）。
- 床帘、纱窗、蚊帐只能使用免打孔产品；蚊帐凉席本地难买合适的，需要就国内买。
- 冰箱、洗衣机等大型电器不能搬入宿舍；电磁炉等烹饪器具宿舍禁止使用（C13），本地商场有售不代表宿舍可用。
- 洗脸盆、扫把、垃圾桶、抹布、衣架等，到校后去学校超市或校外商场购买即可；学校附近蚊子不多、会定期杀虫，驱蚊用品本地也能买到（P28 可到校再买）。

## 三、推荐使用顺序（导览 PDF 04 / 09）

**02 选 → 03 办 → 04 核 → 01 称；05 备查；06 速查。**

1. **第一步 · 02 表**：逐项确认“携带策略”（随身/国内带/国内带·可海运/到校再买/不带/按需），这是后面所有动作的源头。
2. **第二步 · 03 + 04 表**：办理项逐条更新状态、三层合规核对；不写完整证件号/银行卡号。
3. **第三步 · 01 表**：装箱后填 E7/E8 实称与 H7/H8 时间；增减或改分装后重新称重；18kg/6kg 只是预算目标。
