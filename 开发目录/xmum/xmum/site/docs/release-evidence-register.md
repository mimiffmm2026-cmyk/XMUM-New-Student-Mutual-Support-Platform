## 隐私、版权与公开边界

- 本登记只保存文件路径、数量、页数、尺寸、摘要和证据等级，不复制个人身份字段、登录凭据、群组标识、个人联系方式或可执行的付款资料。
- 截图与攻略仅用于内部核验，不随页面发布，也不因记录摘要而获得再分发授权。
- 页面公开展示的校园照片、校园地图和家庭预算估算表均使用本地副本，并在图注中标明可确认的作者与来源；不复制官网版式、按钮或大段原文。
- 文件摘要只能证明“审计的是哪个文件”，不能证明内容为官方发布、当前有效或无误。
- 登记不提供网页跳转；正式办理入口应由使用者从本人最新录取材料或当前学校渠道独立确认。

## 发布维护要点

1. 动态日期、费用、签证、入境及联系方式继续以当前系统和最新官方通知为准。
2. 仍标为“需核验”或历史参考的条目不得升级为无条件结论。
3. 页面继续排除凭据、付款明细、个人联系方式、未知版权图片和网页外跳。
4. 每次内容更新后重新运行自动化、单文件导出和浏览器回归。
