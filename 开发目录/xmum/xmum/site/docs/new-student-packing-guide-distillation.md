## 核心原则

- 入学行李优先准备三类：**入境报到**所需、**入住当晚**所需、**个人日常离不开**的物品
- 其余用品根据实际需要，到校后再慢慢补充
- 判断是否需要从国内携带：
  1. 平日生活用习惯的产品 → 建议携带
  2. 第一天到校报到入住需要用到的 → 建议携带
  3. 第二天外出购买后再使用来得及的 → 可以不携带
  4. 即使忘带，本地商场也十分发达，所有产品都能买到

## 一、入境及报到资料

### 随身文件袋（入境和报到时需要使用）

| 资料 | 说明 |
| --- | --- |
| 护照 | 护照原件 |
| 签证资料 | eVAL / VAL、学生 eVISA 或 SEV |
| MDAC 入境卡 | 马来西亚入境卡 |
| 学校资料 | 录取通知书 |
| 个人密封档案 | 随行文件资料 |

以上资料请留意学校官方老师后续说明。

### 备用资料（日常生活可能会用到）

- 电子备份：将护照、签证、录取通知书等资料保存到手机，以备不时之需
- 证件照片：白底二寸证件照电子版
- 身份证件：个人身份证原件，方便国内高铁等其他国内接驳行程使用；马来西亚本地无须使用

### 提醒

- **重要文件不要托运**：护照、签证资料、录取通知书、贵重物品和落地后马上要用的物品都应放在随身行李中

## 二、电子设备与学习用品

### 电子设备（建议国内购买）

- **智能手机**：苹果或安卓系统都适配；鸿蒙系统下载出境易或 GBOX 等软件即可下载国外应用
- **手提电脑**：Windows 一定适配；Mac 绝大部分适配（不适配可以找到替代方案）；尽量不要买鸿蒙系统电脑；正常性能足够适配本科日常需求；使用 AI 频率高或有建模需求的科目可以选择高性能
- **平板电脑**：苹果、安卓、鸿蒙系统都适配；方便日常记录笔记与上下课；并非刚需
- **电子周边**：耳机、手写笔、键盘、鼠标、U盘、网线等
- **计算器**：理工科用科学计算器（推荐型号 fx991CN）；商科用金融计算器（推荐型号 BA II Plus）
- **充电宝**：本地基本没有共享充电宝，有电量焦虑的同学可自行准备；乘机时必须随身携带、不可托运；额定能量不能超过 100Wh（约 27,000mAh）

### 电源

- 英标转换头 2-3 个
- 英标多插位转换头 1-2 个
- 国标插板或英标转国标插板 1-2 个
- 插板可以买 2m 左右的

### 电话卡

- 国内电话卡可开通国际漫游，换成最便宜的保号套餐，仅用于接收国内短信
- 学生长期本地生活不建议买国内数据漫游套餐；家长短期陪同可购买国内数据漫游套餐
- 本地电话卡月包流量套餐约 25 马币左右，可作为外出时的上网联络以及各类本地软件的电话号码绑定

### 银行卡及支付手段

- 支付宝/微信支付可满足所有校内日常需求，校外绝大部分日常需求
- 银联储蓄卡作为提现手段，请确保已开通跨境支付功能（一般默认开通）
- 本地带有银联标识的 ATM 插国内银联卡即可提现马币，收取部分手续费，约 10-25 元/次
- 某些地方性银行有提现马币免手续费服务，如云南的富滇银行、江西的赣州银行、福建的厦门国际银行等
- 信用卡可让家长开通副卡，Visa / Mastercard 都可以，并非必须，可作为备用保险手段
- 本地 TNG 电子钱包比支付宝使用更广泛方便，但也并非必须开通
- 本地银行卡日常使用频率不高，可按个人需要选择性办理；部分本地网购平台要求绑定本地银行卡，但也可以选择 TNG 电子钱包支付

### 学习用品（学校附近都能买到）

- 常用文具：携带平时使用的草稿纸笔及文具袋即可
- 支架摆件：手机、电脑支架和其他摆件可根据自己的桌面习惯准备
- 书籍：教科书不需要自行准备；兴趣书籍可按情况自带；本地书店以英文书籍为主

## 三、宿舍及床上用品

### 宿舍用品（高频提问内容）

| 物品 | 建议 |
| --- | --- |
| 纱窗 | 非必须，只能使用贴墙款；购买前量好尺寸；本地也可以买到 |
| 电厨具 | 宿舍小锅国内质量更好，建议国内购买；电磁炉等常用烹饪器具本地商场选择很多 |
| 除湿盒 | 学校附近或本地商场可买到；如果准备除湿器，最好在国内买 |
| 吹风机 | 需自行配备，宿舍不提供；本地商场选择很多 |
| 熨斗 | 本地商城可买到，也可从国内自带；宿舍空间不大，建议买便携式 |
| 台灯 | 非必须，视个人情况准备；舍友早睡需要开灯可以准备；可选择本地购买 |
| 门封条 | 担心走廊噪音可贴门缝密封条，一定程度减弱；国内网购或本地都能买到 |

### 床上用品

- **床铺用品**（枕头 / 枕套 / 被子 / 被套 / 床单）：自带的用起来更舒服；可真空压缩后托运、国内购买后海运到校、或报到后去市区商场购买
- **床垫**：学校提供床垫，中等偏硬；想睡软一点的可以自行购买床褥；大马商场可买到合适尺寸，也可国内买好后海运到校
- **床帘**：非必须，视个人情况准备；建议国内购买后海运到校（大马本地很难买到合适的）
- **蚊帐凉席**：非必须，可以不准备；如有需要最好国内买

### 宿舍用品小贴士

- 学校不提供枕头、被子、床单，需自行准备
- 被子不用太厚，空调被即可
- 冰箱、洗衣机等大型电器不能搬入宿舍
- 眼罩、耳塞等用品按个人需求准备
- 选择海运或本地购买的产品，要做好第一天到达后晚上可能无法使用的准备
- 床帘、纱窗及蚊帐只能使用免打孔的产品
- 洗脸盆、扫把、垃圾桶、抹布、衣架等一般宿舍用品，可以到达学校后在超市或校外商场购买
- 学校蚊子不多，会定期杀虫

## 四、衣物与食物

### 衣物（选择合身且符合个人风格的款式）

- **日常衣物**：日常通勤的夏装；寒假回国下飞机的冬装（本地基本用不上）；合适的睡衣、贴身衣物；薄外套、长裤或防晒衣（防止室内过凉、室外过晒）；运动服、泳衣泳裤泳帽
- **正装**：白衬衫 + 黑长裤一套即可；女生也可以穿过膝长裙；西装外套、皮鞋等不作强制要求；本地商场购买也可以
- **鞋类**：运动鞋、日常通勤鞋和拖鞋
- **防晒防雨**：折叠伞、帽子及个人习惯使用的防晒用品；本地商场购买选择也很多
- **女性用品**：有用惯的品牌可以从国内购买携带；本地屈臣氏 / 万宁 / 超市购买也很方便，但品牌不一定相同

### 衣物小贴士

- 国际大牌运动服、时装、泳装等衣物，本地大商场都能买到；行李过多可先带一部分衣物
- 正装主要应对课堂演讲、毕业答辩等情况，使用频率并不高
- 马来西亚全年整体偏热，学校、商场等室内空间可能偏冷；日常以夏装为主，准备一两件薄外套和长裤即可

### 食品（选择小众特别的零食或家乡特产）

- **零食**：学校附近能买到很多国内零食；建议携带更多小众、市面上难买的产品
- **泡面**：学校附近能买到很多国内品牌泡面；可以准备 1-2 包应急
- **家乡特产**：家乡特产、调料等本地可能很难买到，有需要的可以携带
- **调味料**：学校附近能买到很多国内品牌；可准备市面上难买的小众调味料；本地商场购买选择也很多

### 食品小贴士

- 大量零食干粮、调味料建议入学一段时间后，摸清附近商店情况再统一集运购买
- 国内超市能买到的大众品牌，学校附近基本都能买到，例如：老干妈、乌江榨菜、康师傅方便面、好欢螺螺蛳粉、旺旺雪饼、豆豉鲮鱼、娃哈哈八宝粥、海底捞火锅底料、海天酱油、王守义十三香等等
- 本地中超可买到调料

## 五、日用品与药品

### 日用品（个人护理 / 清洁用品 / 餐具工具）

- 洗发水、沐浴露、护发素等大瓶装液体可以到校后再购买；如需提前准备，旅行装或分小瓶即可
- 化妆品、护肤品、一次性擦脸巾等个人偏好的产品建议国内购买；本地不一定能买到同样款式或品牌
- 单瓶液体超 100 毫升只能托运，不能随身携带上飞机
- 饭盒饭碗、水杯、筷子勺子、牙刷、指甲刀等产品本地也能买到

### 如何判断是否需要从国内携带

- 个人平日生活用习惯的产品，建议携带
- 第一天到校报到后入住需要用到的产品，建议携带
- 第二天外出购买后再使用都来得及的产品，可以不携带
- 即使忘带，本地商场也十分发达，所有产品都能买到

### 药品与护理

- **常用药品**：感冒药、止泻药、胃药、过敏药、止痛药、口腔溃疡药等；可从国内携带少量；学校附近也能买到部分国内常用药；本地诊所、药房都能买到相对应的药物
- **长期用药**：按个人需要准备；入境时尽量携带处方、医生证明或相关病历，以备不时之需
- **基础用品**：创口贴、体温计、口罩及简单消毒用品；可以在本地购买
- **护理用品**：眼镜、隐形眼镜、护理液、眼药水和个人常用护理用品；不一定买到国内相同品牌，但有替代产品；可按自身适应程度选择自带或本地购买
- **防蚊用品**：止痒膏、防蚊喷雾、花露水、风油精等学校附近也可以购买到
- **其他产品**：板蓝根、藿香正气丸、999 感冒灵、夏桑菊颗粒、健胃消食片、红霉素软膏等国内药物品牌，建议国内购买

### 马来西亚药物携带限制

- 含有「麻黄碱」成分的感冒药等
- 含有「可待因 / 吗啡」成分的止咳止痛药等
- 含有「多潘立酮」成分的胃药等
- 精神、安眠与兴奋剂类药物
- 含有「士的宁」成分的跌打万花油、关节炎膏等
- 任何有动物成分的中药：熊胆粉、牛黄解毒丸等

以上产品请尽量不要携带；如需携带，请准备好相关医生证明。

## 六、采购地点

### 校内：学校超市 / 便利店

- 店铺：B1 活动楼 LG 层学校超市；D6 食堂 G 层便利店
- 距离：宿舍步行 5 分钟
- 营业时间：学校超市 08:00-02:00；便利店 08:00-22:00
- 采购建议：适合临时采购；新生入学季物品容易脱销

### BELL Avenue Sunsuria City（学校对面商业街）

- 店铺：闽桂中国超市、薯嘟嘟中国超市、你好同学文具店、711 便利店 / KK 便利店等
- 距离：学校步行 8 分钟
- 营业时间：中国超市 11:00-02:00；文具店 12:30-21:00；便利店 24 小时
- 采购建议：适合临时采购；货物比校内超市品种多且齐全一些，中国货为主

### Pasar Malam Kota Warisan（学校附近本地夜市区）

- 店铺：Kaisar 药房 / Pharmart 药房；YL Mart 文具店 / GH Solution 文具店；MR.DIY 日用工具店；711 便利店 / KK 便利店等
- 距离：学校步行 10 分钟
- 营业时间：10:00-22:00；文具店一般只营业到下午 6 点
- 采购建议：适合买日用品和工具，价格实惠；中国货偏少，本地货居多

### KIPMall（学校附近小商场）

- 店铺：屈臣氏；Health Lane Family 大药房；Hasani 书店；Econsave 宜康省大型超市；MR.DOLLAR 一元店 / MR.DIY 日用工具店；HappyHome 家居城 / Jimart 家具店；以及各类眼镜店、服饰服装店等等
- 距离：学校打车 7 分钟
- 营业时间：10:00-22:00
- 采购建议：小型综合商场，适合一次性集中采购，价格实惠；本地货居多，部分国际品牌货

### IOI City Mall（学校最近的一线豪华商场）

- 店铺：AEON 高端超市 / Lotus's 日常超市；大牌美妆 / 护肤品；国际运动品牌；各大电子产品品牌门店；大型电器城、大型床上用品店、大型装潢家具城、大型书店、大型电影院等等；无印良品、优衣库、迪卡侬、大疆、海底捞等等
- 距离：学校打车 25 分钟
- 营业时间：10:00-22:00
- 采购建议：大型综合性商场，全部逛完需 3-5 小时，适合一次性集中采购；中日韩、欧美等国际品牌货居多，适合购买大牌或特定产品
- 采购提示：
  - IOI 城市广场所有类型的日用品都能买到；建议入学报到后找一天时间专门来这里采购
  - 相比去吉隆坡市中心（车程约 50 分钟），这里只需 25 分钟车程
