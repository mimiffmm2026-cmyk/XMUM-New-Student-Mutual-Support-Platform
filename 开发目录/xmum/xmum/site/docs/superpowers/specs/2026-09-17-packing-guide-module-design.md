# 行李准备板块设计（packing guide module）

> **历史设计说明（2026-10-05）：** 本规格记录早期 54 项方案；当前公开实现已扩展为 67 项，本文中的 54 项仅保留为历史决策背景。

日期：2026-09-17
状态：待用户审阅
来源工作稿：`docs/new-student-packing-guide-distillation.md`、`docs/packing-master-list-v4-distillation.md`

## 1. 背景与目标

站内已有入学时间线、签证材料、校园生活、食堂攻略等板块，但没有行李准备内容。两份蒸馏稿（第三方经验指南 + 用户自制总清单 v4）已经过逐页核对，现要把其中适合公开的内容做成站内新板块，形态对齐食堂攻略模块。

目标：给新生一份「带什么、到哪买、怎么合规」的可筛选参考，并保持本站既有发布边界（非官方、无外链、动态信息标注时点、敏感内容排除）。

## 2. 已确认决策

1. **范围**：四问法 + 54 项清单 + 采购地图 + 合规速查 + 首晚提醒。不上 R01–R24 报到时间线（与站内五阶段时间线重复），不上 01 表重量预算（个人规划工具）。
2. **版位**：`#guide`（入学时间线模块）内，与 `#timeline`、`#visa-materials` 并列的折叠子区，anchor 为 `#packing`，默认折叠。不改顶部导航。
3. **署名**：页面点名致谢微信公众号「大马口袋」及家长整理资料，不提供外链。合规内容另行标注以航司/海关/学校最新要求为准。
4. **清单形态**：按携带策略分 4 区，筛选维度为人群 + 分类。

**筛选语义**：

- 策略：全部（默认）｜4 个策略分组。与分组区同构（如食堂的区域筛选），同时保证空组合可达、空状态不是死代码。
- 人群：全部（默认）｜男女通用｜女生侧重｜男生侧重。选「女生侧重」＝显示 男女通用 + 女生侧重；选「男生侧重」同理；选「男女通用」只显示通用项。
- 分类：全部（默认）｜8 类。
- 结果计数 `aria-live`：「显示 X / 54 项」；无结果显示空状态文案。

**公开版对源数据的修正**：

- P52 插排：策略由「国内带」改为「到校再买」（原表策略列与安排列冲突，按要点语义归组）。
- P39 药品：条目保留（策略仍为国内带），优先级与要点按原语义呈现「按需、逐药核」，强调由医生/药师按本人情况判断。
- 不发布原表的个人列：本次安排、准备状态、本次数量、本人记录、重量分组、来源编号。
- 不发布个人额度 20kg/7kg；合规区改为中性表述「按各段票规分别称重，两类额度不合并」。
- 要点中的 C01–C15 内部编号改写为自然语言（如「按航空液体规则」）；Pxx 编号仅保留在数据与测试钩子中，不在公开列表显示，要点中的 Pxx 交叉引用改写为物品名。

### 3.4 采购地点地图

静态 6 档表：校内超市/便利店、BELL Avenue·Sunsuria City、Pasar Malam Kota Warisan 夜市、KIPMall、IOI City Mall、吉隆坡市中心。含距离、营业时间、代表店铺、采购建议。注释：整理于 2026.09，可能已变化，以现场为准。

### 3.5 合规速查

按三层组织（C01–C15 合并改写为约 10 条行动条目）：

- 海关/检疫：肉干肉类零食；花草药材种子食品；现金及无记名票据申报（≥等值 USD10,000）；新购物品与礼物；申报≠放行。
- 航空：液体膏体喷雾（随身 ≤100mL 容器、透明可封口袋）；充电宝（≤100Wh、0–1 只，不可托运；含境内段核 3C 与召回）；备用电池与设备内置电池；刀具剪刀理容工具；两类额度分别称重不合并。
- 宿舍：电器与插排、禁止房内烹饪；口香糖等校内限制；海关可入≠宿舍可用。
- 药物携带限制（C03 + 受控成分表 6 类：麻黄碱、可待因/吗啡、多潘立酮、精神/安眠/兴奋剂、士的宁、动物成分中药），行动指引：尽量不携带，确需携带备好医生证明与英文译件。

注释：本区为整理提示，不构成法律意见；以航司、海关及学校最新要求为准；不代答个案。

### 3.6 首晚与床品提示

4–5 条：首晚交付必须实际可领取（供应方/领取/接收人/备选）；真空压缩只减体积；床帘纱窗蚊帐限免打孔；大型电器不可入宿舍；洗脸盆垃圾桶衣架等到校再买。不复述站内已有床铺尺寸，文字指向「校园生活」板块。

## 4. 技术设计

### 4.1 `app/packing-content.ts`

纯数据 + 纯函数，测试可直接 import（`--experimental-strip-types`）：

- 类型：`PackingItem`、`PackingMethodRow`、`ShoppingSpot`、`ComplianceRule`、`ControlledIngredient`、`PackingFilterState`
- 常量：`packingUpdatedAt = "2026.09"`、`packingGroups`（4）、`packingCategories`（8）、`packingItems`（54，源自 xlsx 02 表逐条转录）、`packingMethods`、`shoppingSpots`（6）、`complianceRules`、`controlledIngredients`（6）、`firstNightNotes`
- 纯函数：`filterPackingItems(items, filters)`、`groupPackingItems(items)`

### 4.2 `app/PackingGuide.tsx`

Client component，无 props，形制对齐 `app/DiningGuide.tsx`：

- `<details className="packing-section secondary-section" id="packing">` 默认折叠
- 筛选芯片两行（`role="group"`、`aria-pressed`、`data-packing-filter-group` / `data-value`）
- `aria-live` 计数与空状态
- 策略分组表：列＝物品/人群/优先级·条件/建议数量/要点；`data-label` 移动端卡片化；交互钩子 `data-packing-*`
- 静态区（四问法、采购地图、合规、首晚）为普通 JSX
- 键盘可达、触控目标 ≥44px
